# AGENTS.md

Guidance for coding assistants working in this repository.

- [`CLAUDE.md`](CLAUDE.md): commands, dependency management, branch and commit conventions,
  the E2E selector convention with the `data-testid` reference, and GitPM (`.meta/`).
- [`CONSTITUTION.md`](CONSTITUTION.md): architecture, module boundaries, naming and dependency
  rules. All code must comply with it.
- [`.claude/rules/`](.claude/rules/): code style, testing (TDD, 100% coverage of changed lines),
  the Given/When/Then scenario format for tests, and the git workflow.
