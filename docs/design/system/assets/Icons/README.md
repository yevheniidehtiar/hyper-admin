The Lucide (ISC licence) outline icons the components use (35 in the design system: `receipt` for Bills and the Wave 1 set `ellipsis`, `download`, `upload`, `copy`, `mail`, `refresh-cw`, `clock`, `circle-help`, `columns-3`, `sparkles`), at 20px with a 1.5px stroke, with `stroke="currentColor"` so an inlined icon takes the text colour in both themes. (The design-system artifact keeps a #4B5565 copy so the files preview as images.)

Mirror in RTL with `.ha-icon--mirror`: `chevron-right` (and the other chevrons when used for back/forward). Never mirror: `check`, `circle-check`, `arrow-up`/`arrow-down` (sort and delta), `search`, `globe`, `calendar`, `bar-chart-3`.

**In this repository:** `src/hyperadmin/static/icons/` holds those 35 plus four the admin views added (`chevron-left`, `eye`, `lock`, `log-out`), 39 in all. Templates inline them through the `icon(name)` macro in `templates/components/_icons.html`, generated by `scripts/generate_icon_macro.py`; add further icons from the same pinned Lucide release and rerun it.
