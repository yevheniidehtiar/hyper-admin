# HyperAdmin Roadmap

The roadmap lives on the documentation site:
**[Roadmap](https://yevheniidehtiar.github.io/hyper-admin/roadmap/)**
(source: [`docs/roadmap.md`](docs/roadmap.md)).

It lists what 1.0 includes, what is not in 1.0 (the JSON REST API and multi-tenancy were
dropped; record history, more ORM backends and AI-assisted features are not scheduled), and
the known gaps 1.0 ships with. Per-release detail is in [`CHANGELOG.md`](CHANGELOG.md).
