# HyperAdmin — ERP demo

A live instance of the ERP example from
[HyperAdmin](https://github.com/yevheniidehtiar/hyper-admin), a Pydantic-native admin
interface for FastAPI powered by HTMX.

Sign in with **demo / demo**. The demo account can manage every ERP record (contacts,
invoices, bills, accounts, journal entries) but not users, groups or permissions.

The data is synthetic and resets every night and on every deploy. Anything you enter is
visible to other visitors until then, so please don't type real personal data.

This Space is deployed automatically from the `develop` branch; source and issues live on
[GitHub](https://github.com/yevheniidehtiar/hyper-admin).
